billion-context：ASCII 交互原理演示

观察模型输入中的原文块如何收缩、摘要如何逐层合并，以及原文引用如何保留。再与独立 Pi 子进程中的任务派发对照。

教学模拟，不是实时会话或性能测试。50K → 1K 与每四块晋升均为示意参数；实际范围、时机与摘要大小由模型选择。固定输入与回执大小经过简化。

第 4 批原文即将收缩为 b4 摘要

教学缩放：每批原文 50K → T1 摘要 1K；4 个摘要块 → 上层摘要 1K。

默认解压取上一层；full:true 请求原文。大文本可能先写入文件，再按需读取。delegate 属于独立机制，子会话内部也可以使用压缩。

acp_delegate：把任务交给独立会话

ASCII / Pi / async=true
0 / 7
上下文独立 · 工作目录默认共用 · 新任务通过 stdin 传入模型选择：调用参数 → 角色配置 → 父模型；print / JSON 模式会改用同步等待。

可离线运行。浏览器允许时仅在本机保存交互进度；不会启动真实代理或修改项目文件。
